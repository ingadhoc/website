============================
Website Sale Hide All Prices
============================

This module allows the users to hide all the prices of the eCommerce. All prices on the eCommerce site will be hidden, but customers will be able to add products to the cart in order to request a quotation.

Installation
============

To install this module, you need to:

#. Just install this module.

Configuration
=============

To configure this module, you need to:

#. Go to Settings > Website > eCommerce and activate the feature "Hide all prices in my eCommerce".

Usage
=====

To use this module, you need to:

#. Customers browse the shop and add products to the cart without seeing prices (product pages, lists, search suggestions, comparison, wishlist and cart).
#. At checkout, once the addresses are saved, the "Request Quotation" button replaces the payment step.
#. The order stays as a draft quotation for the sales team, and the customer is redirected to the "Request Quotation Received" page.
#. The "payment succeeded" mail is not sent to the customer.
